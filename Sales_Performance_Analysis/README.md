# Sales Performance Analysis
**Tools:** Excel, SQL, Power BI (Power Query and DAX)

## Objective
Analyze sales, profit, product/category mix, regional performance, discounts, segments, channels, and basic data quality.

## Deliverables
- `data/sales_data_raw.csv`: 1,600-row synthetic dataset with intentional issues.
- `data/sales_data_cleaned.csv`: normalized and flagged data for reporting.
- `excel/sales_performance_analysis.xlsx`: raw, cleaned, monthly summary, and KPI summary sheets.
- `sql/sales_performance_analysis.sql`: KPI, monthly, regional, product, and quality queries.
- `powerbi/measures.dax`: DAX measures.
- `powerbi/power_query_m.txt`: Power Query starter.
- `powerbi/dashboard_build_guide.md`: report layout and build steps.

**Data integrity:** This uses synthetic practice data, not actual company sales. A completed `.pbix` is not included; use the guide to build and save the Power BI report before claiming it is published.
