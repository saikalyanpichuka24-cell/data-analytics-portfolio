# Data Analytics Portfolio — Excel, SQL & Power BI
Two end-to-end junior Data Analyst portfolio practice projects:
1. **Location Data Quality & Process Analysis** — data validation, duplicates/missing values, review KPIs, SQL, Excel QA workbook, Power BI build guide.
2. **Sales Performance Analysis** — sales/profit trends, product/category and regional performance, SQL, Excel workbook, Power BI build guide.

Includes synthetic CSV datasets, cleaned datasets, Excel workbooks, SQL queries, DAX measures, Power Query M starters, and dashboard specifications. These are practice datasets; no real employer data is included. Completed Power BI `.pbix` files are not included.
