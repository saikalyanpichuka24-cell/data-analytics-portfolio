# Location Data Quality & Process Analysis
**Tools:** Excel, SQL, Power BI (Power Query and DAX)

## Objective
Evaluate location-review process throughput and find data-quality issues such as missing regions, invalid coordinates, negative error counts, inconsistent status labels, and duplicate record IDs.

## Deliverables
- `data/location_reviews_raw.csv`: 650-row synthetic raw dataset with intentional issues.
- `data/location_reviews_cleaned.csv`: normalized and flagged dataset for dashboarding.
- `excel/location_data_quality_analysis.xlsx`: raw, cleaned, and QA summary worksheets.
- `sql/location_data_quality_analysis.sql`: SQL KPI and quality-check queries.
- `powerbi/measures.dax`: Power BI DAX measures.
- `powerbi/power_query_m.txt`: Power Query starter.
- `powerbi/dashboard_build_guide.md`: report-page design and build steps.

**Data integrity:** This is a synthetic practice project, not actual employer data or proof of production work. A completed `.pbix` is not included; follow the build guide in Power BI Desktop and save your own report.
