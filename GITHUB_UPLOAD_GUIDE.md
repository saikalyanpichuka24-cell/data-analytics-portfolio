# GitHub upload
1. Extract the ZIP.
2. Open your repository → Add file → Upload files.
3. Upload the two project folders and the root README.
4. Commit message: `Add Excel SQL and Power BI portfolio projects`.
5. For each project, keep the README visible in GitHub and link to the folder from your portfolio page. Build the report in Power BI Desktop using the dashboard guide, then add screenshots or the published report link once actually completed.
